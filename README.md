# Enhancing Video Anomaly Detection through Dual-Path Reconstruction and Diverse Pseudo-Anomaly Generation

Official PyTorch implementation of the manuscript **"Enhancing Video Anomaly Detection through Dual-Path Reconstruction and Diverse Pseudo-Anomaly Generation"**, submitted to **The Visual Computer**.

## Overview

This paper proposes a video anomaly detection framework based on a Multi-Source Pseudo-Anomaly Generator and a Dual-Decoder Framework. The generator integrates spatiotemporal perturbations, including frame skipping, motion shuffling, and Gaussian noise, with an object-level local appearance perturbation strategy based on YOLOv3 and CIFAR-100.

The dual-path decoder is equipped with independent memory modules $M_n$ and $M_p$. The normal path reconstructs normal samples, while the pseudo-anomaly path serves as an auxiliary negative-learning branch that discourages accurate reconstruction of synthetically perturbed samples. This design encourages the separation of normal and pseudo-anomalous representations.

## Points

### Datasets

To validate and benchmark our method against the state of the art, we conduct experiments on three datasets: [UCSD Ped2](http://www.svcl.ucsd.edu/projects/anomaly/dataset.htm), [CUHK Avenue](http://www.cse.cuhk.edu.hk/leojia/projects/detectabnormal/dataset.html), and [ShanghaiTech](https://svip-lab.github.io/dataset/campus_dataset.html).

Specify the dataset root using:

```bash
--data_root "/path/to/dataset"
```

### YOLOv3 Weights

Download the YOLOv3 weight file and place it at:

```text
Yolov3/yolov3/weights/yolov3-spp-ultralytics.pt
```

[Download YOLOv3 weights](https://drive.google.com/file/d/1n4Yazein383Q9LXsW1oHXeFib-HlO1w4/view?usp=drive_link)

### CIFAR-100 Dataset

CIFAR-100 is used to construct object-level local appearance perturbations. Place the dataset in:

```text
dataset/cifar100/
```

The expected structure is:

```text
dataset/
└── cifar100/
    └── cifar-100-python/
```

If the dataset is not found, the code will attempt to download it automatically using `torchvision.datasets.CIFAR100`.

### Anomalies

We simulate anomalous behavior using a Multi-Source Pseudo-Anomaly Generator covering temporal and spatial dimensions. The pseudo-anomalies include frame skipping, motion shuffling, Gaussian noise, and object-level local appearance perturbation using YOLOv3 and CIFAR-100.

The pseudo-anomaly sampling probability `p` is controlled by the --pseudo_anomaly argument. Temporal perturbations are implemented in `data.py`, Gaussian noise is added in `utils.py`, and object-level perturbations are generated by `Object_Mask.py`.
